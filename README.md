# 🎓 Abirux Interview Coach

**Abirux Interview Coach** est un agent IA conçu pour transformer votre préparation aux entretiens d'embauche. Saisissez votre poste, et laissez l'IA créer un parcours sur mesure.

## ✨ Fonctionnalités
- 🖼️ **Visuels Dynamiques** : L'interface s'adapte à votre métier.
- 🎯 **6 Modules Personnalisés** : Générés automatiquement selon le poste visé.
- 💬 **Simulation Interactive** : Chatbot intelligent pour pratiquer vos réponses.
- 📊 **Feedback & Correction** : Recevez une note et la réponse idéale pour chaque question.

## 🛠️ Tech Stack
- **Python / Streamlit**
- **Groq Cloud API (Llama 3.1)**
- **CSS / Pillow**

## 🚀 Installation
1. Installez les dépendances : `pip install streamlit groq Pillow`
2. Lancez l'app : `streamlit run app.py`
